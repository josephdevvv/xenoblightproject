# Void Mite — 4 Direction Complete Pack

## Directions
`south_east`, `south_west`, `north_east`, `north_west`

## Included actions
- `Idle`: 1 frame, 48×32 px per frame
- `Walk`: 6 frames, 48×32 px per frame
- `Attack_Stomp`: 6 frames, 48×32 px per frame
- `Hit_Reaction`: 4 frames, 48×32 px per frame
- `VFX_Stomp_Impact`: 3 frames, 48×32 px per frame — separate overlay; play it at attack contact
- `Death_Fall`: 6 frames, 64×48 px per frame

Each action/direction contains:
- `frames/` — individual transparent PNGs
- `sheet/` — horizontal Sprite Sheet PNG

This package intentionally contains only the four Xenoblight monster directions and final game-ready files. It omits source generations and QA previews.
